# MVP_ROADMAP.md

# CakeBazar MVP Roadmap

# نقشه راه MVP

---

# Purpose

# هدف

This roadmap defines what CakeBazar will build during the first 24 months.

The goal is not to build every idea.

The goal is to validate the business as quickly as possible.

---

هدف این سند مشخص کردن مسیر ساخت CakeBazar در 24 ماه اول است.

هدف ساخت همه ایده‌ها نیست.

هدف اعتبارسنجی سریع کسب‌وکار است.

---

# Product Development Philosophy

# فلسفه توسعه محصول

## English

Build less.

Learn faster.

Validate before scaling.

Do not build features before proving demand.

---

## فارسی

کمتر بساز.

سریع‌تر یاد بگیر.

قبل از توسعه گسترده اعتبارسنجی کن.

هیچ قابلیتی قبل از اثبات نیاز بازار ساخته نمی‌شود.

# Strategic Rule

# قانون استراتژیک

If a feature does not help:

* Acquire sellers
* Acquire customers
* Generate orders

it should not be built during MVP.

---

اگر یک قابلیت به:

* جذب فروشنده
* جذب مشتری
* ایجاد سفارش

کمک نکند،

نباید در MVP ساخته شود.

---

# Kill List

# لیست حذف

The following ideas are NOT allowed during MVP:

* Academy
* Live Streaming
* AI Agents
* Supply Marketplace
* Installment Plans
* Corporate Portal
* Advanced Analytics
* Delivery Network

Reason:

Focus.

---

دلیل:

تمرکز.

---

# Success Definition

# تعریف موفقیت

CakeBazar MVP is successful if:

* 100 Sellers join
* 1000 Orders are completed
* Customers return
* Sellers remain active

Not if:

* 100 features are built.

---

موفقیت MVP زمانی است که:

* 100 فروشنده فعال داشته باشیم.
* 1000 سفارش واقعی ثبت شود.
* مشتریان بازگردند.
* فروشندگان فعال بمانند.

نه زمانی که 100 قابلیت ساخته شده باشد.

---

# Founder Rule

# قانون بنیان‌گذار

When a new idea appears:

Do not build it.

Add it to:

docs/ideas/

Only after validation can it enter the roadmap.

---

هر ایده جدید ابتدا وارد پوشه ideas می‌شود.

فقط پس از اعتبارسنجی اجازه ورود به Roadmap را خواهد داشت.
