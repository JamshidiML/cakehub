# CUSTOMER JOURNEY
# سفر مشتری

## Journey CJ-01

Need → Discovery → Trust → Order → Celebration → Loyalty

---

نیاز → کشف → اعتماد → سفارش → جشن → وفاداری

---

### Step 1: Need Recognition
### مرحله ۱: ایجاد نیاز

User realizes an upcoming event.

Examples:

- Birthday
- Anniversary
- Wedding
- Graduation
- Baby Shower
- Corporate Event

User Goal:

"I need this celebration to be successful."

User Emotion:

Concerned

Success Metric:

User starts searching.

---

کاربر متوجه نزدیک شدن یک مناسبت می‌شود.

مثال‌ها:

- تولد
- سالگرد ازدواج
- عروسی
- فارغ‌التحصیلی
- جشن نوزاد
- مراسم سازمانی

هدف کاربر:

«می‌خواهم این جشن موفق باشد.»

احساس:

نگرانی

معیار موفقیت:

شروع جستجو

---

### Step 2: Discovery
### مرحله ۲: کشف

User discovers CakeBazar.

Channels:

- Google
- Instagram
- Referral
- Advertisement
- Direct Visit

User Goal:

Find trusted cake options.

User Emotion:

Curious

Success Metric:

User views listings.

---

کاربر با CakeBazar آشنا می‌شود.

کانال‌ها:

- گوگل
- اینستاگرام
- معرفی دوستان
- تبلیغات
- مراجعه مستقیم

هدف:

پیدا کردن گزینه‌های قابل اعتماد

احساس:

کنجکاوی

معیار موفقیت:

مشاهده لیست فروشندگان

---

### Step 3: Seller Evaluation
### مرحله ۳: ارزیابی فروشنده

Decision Factors:

- Cake Design
- Price
- Reviews
- Reliability Score
- Verification Badge
- Delivery Coverage

User Goal:

Find a trustworthy seller.

User Emotion:

Uncertain

Success Metric:

Seller profile viewed.

---

فاکتورهای تصمیم‌گیری:

- طراحی کیک
- قیمت
- نظرات
- امتیاز اعتماد
- نشان تأیید
- محدوده ارسال

هدف:

یافتن فروشنده قابل اعتماد

احساس:

تردید

معیار موفقیت:

بازدید از پروفایل فروشنده

---

### Step 4: Product Selection
### مرحله ۴: انتخاب محصول

Filters:

- Budget
- Event Type
- City
- Delivery Date
- Style

User Goal:

Choose the best option.

User Emotion:

Hopeful

Success Metric:

Add to order request.

---

فیلترها:

- بودجه
- نوع مراسم
- شهر
- تاریخ تحویل
- سبک طراحی

هدف:

انتخاب بهترین گزینه

احساس:

امیدواری

معیار موفقیت:

ثبت درخواست سفارش

---

### مرحله ۵: ثبت سفارش

User submits:

- Date
- Address
- Time
- Notes

User Goal:

Complete order quickly.

User Emotion:

Relieved

Success Metric:

Order confirmed.

---

کاربر اطلاعات سفارش را ثبت می‌کند:

- تاریخ

- توضیحات

هدف:

احساس:

آسودگی

معیار موفقیت:

تأیید سفارش

---

### Step 6: Pre-Celebration Tracking
### مرحله ۶: پیگیری قبل از جشن

Features:

- Notifications
- Delivery Tracking
- Status Updates

User Goal:

Reduce anxiety.

User Emotion:

Anticipation

Success Metric:

No support ticket.

امکانات:

انتظار

معیار موفقیت:

---

### Step 7: Delivery
### مرحله ۷: تحویل

Cake arrives.

Critical Moment.

User Goal:

Receive cake safely and on time.

User Emotion:

High Expectation

Success Metric:

Successful Delivery

---

کیک تحویل داده می‌شود.

این مهم‌ترین لحظه سفر مشتری است.

معیار موفقیت:

تحویل موفق

Joy

Positive Experience

---

جشن برگزار می‌شود.

Repeat Purchase

# North Star Journey
# سفر ستاره شمالی

Customer has an important celebration.

↓

Finds CakeBazar.

↓

Trusts CakeBazar.

↓

Places Order.

↓

Receives Cake On Time.

↓

Celebration Succeeds.

↓

Returns Next Time.

---

مشتری یک مناسبت مهم دارد.

↓

CakeBazar را پیدا می‌کند.

↓

به CakeBazar اعتماد می‌کند.

↓

سفارش ثبت می‌کند.

↓

سفارش را به موقع دریافت می‌کند.

↓

جشن با موفقیت برگزار می‌شود.

↓

برای مناسبت بعدی بازمی‌گردد.
