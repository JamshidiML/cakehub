# USER_STORIES.md

# CakeBazar User Stories

# داستان‌های کاربری CakeBazar

---

# Purpose
# هدف

This document translates user journeys into actionable product requirements.

Each user story follows:

As a [User]
I want [Action]
So that [Outcome]

---

این سند سفر کاربران را به نیازمندی‌های قابل توسعه تبدیل می‌کند.

فرمت:

به عنوان [کاربر]

می‌خواهم [عملی انجام دهم]

تا بتوانم [هدف مورد نظر را محقق کنم]

---

# Founder Reminder

Users do not buy features.
