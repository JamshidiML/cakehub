# Purpose

# هدف

This document contains ideas related to payments, financing, credit systems, subscriptions, wallets, rewards, and financial services.

The goal is to create a financial ecosystem around celebrations.

---

این سند شامل ایده‌های مرتبط با پرداخت، اعتبار، اقساط، کیف پول، اشتراک و خدمات مالی است.

هدف ایجاد یک اکوسیستم مالی پیرامون صنعت مناسبت‌ها است.
