# Quarterly Review

Every quarter:

* Reprioritize ideas
* Move validated ideas forward
* Pause low-value initiatives
* Add newly discovered opportunities

---

هر سه ماه:

* اولویت‌ها بازبینی شوند
* ایده‌های تأییدشده جلو بروند
* ایده‌های کم‌ارزش متوقف شوند
* فرصت‌های جدید اضافه شوند
