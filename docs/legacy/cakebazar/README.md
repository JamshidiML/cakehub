# CakeBazar

CakeBazar is a trust-first marketplace for custom cakes and celebration moments.

The project direction from the shared ChatGPT conversation has shifted from a simple
home-cake landing page into a marketplace product: customers need confidence that
their celebration will not fail, and sellers need a clear way to earn trust,
receive orders, and grow without relying only on social media messages.

## Product North Star

The safest and most trusted way to organize a celebration.

## Founder Rule

When a decision is difficult, choose the option that increases trust the most.

## MVP Focus

The MVP should validate a focused marketplace before expanding into a full
celebration ecosystem.

Core MVP scope:

- Verified seller onboarding
- Seller profiles
- Cake listings
- Category and city-based discovery
- Custom order requests
- Reviews and reliability signals
- Admin review and moderation
- Lightweight notifications

Out of scope for the first MVP:

- Academy
- Supplier marketplace
- Corporate platform
- BNPL
- Full AI platform
- Event management suite

## Next Build Step

Start with a small marketplace prototype:

- Customer browse and search flow
- Seller profile and listing pages
- Custom order request form
- Seller verification and reliability score placeholders
- Admin dashboard for approving sellers and listings
