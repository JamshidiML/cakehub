# CakeBazar Experiment Backlog

## Purpose

This backlog translates product assumptions into experiments. Each experiment
should produce a decision: continue, change, or stop.

## Scoring

Priority is based on:

- Impact on trust
- Impact on conversion
- Risk reduction
- Effort to run

## Experiments

## First Sprint Experiments

Run these first:

1. E001: trust card test
2. E002: seller willingness pilot
3. E003: structured order form test
4. E004: focused launch city test

These experiments validate the marketplace foundation before investing in
payments, AI, corporate workflows, or ecosystem features.
